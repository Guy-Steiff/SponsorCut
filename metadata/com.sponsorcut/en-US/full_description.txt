SponsorCut removes unwanted segments from locally stored video and audio files.

Process media without segmentation, import segment data from local TXT or JSON files, create and edit segments manually, or optionally look up community-provided SponsorBlock segments. SponsorCut can also look up segmentation data for Rumble and Spotify content from a separate database. Imported segment sets can be stored locally and used offline.

SponsorCut processes files on your device. It does not require an account, cloud storage, remote processing, or continuous connectivity. External database lookup is optional.

Features:
- Remove selected segments from local video and audio files
- Process media without segmentation
- Import segment data from local TXT or JSON files
- Create and edit segments manually
- Store imported segment sets locally for offline use
- Optional SponsorBlock community segment lookup
- Optional Rumble and Spotify database lookup
- Supports MP4, MKV, WebM, TS, M4A, MP3, AAC, and Opus files
- URL and file share-intent support for YouTube and Rumble
- Cancel button and wake lock for long jobs
- Diagnostic log for troubleshooting
- Audio files saved to Music/SponsorCut with the correct MIME type

All media processing is performed locally. No analytics, tracking, or accounts are required.

Requires Android 8.0 (Oreo) or later.
